MyToDo

半透明无边框的桌面任务便签，让待办事项安静地留在桌面上。

下载 Windows 版 GitHub 仓库

Windows 10 / 11 · 免安装 · 无需注册登录 · 完全本地运行

功能亮点

🪟 半透明悬浮桌面无边框窗口透出壁纸，任务与桌面融为一体，透明度可自由调节。
📦 解压即用无需安装、无需 Python 环境，下载解压后双击运行；数据存在软件目录，拷走整个文件夹就是备份。
🎨 主题预设深空、暖夜、森林、海洋、薰衣草、素白六套预设，也可自定义颜色、字体与透明度。
🔒 锁定模式一键锁定窗口，防止误拖拽误编辑；Ctrl+L 快速切换。
🕘 历史任务完成与删除的任务进入历史记录，可随时恢复或彻底清除。
🌏 中英双语设置中一键切换中文 / English，重启即生效。
🔄 检查更新设置内一键检查新版本，对接 GitHub Releases。
🛡️ 隐私优先无账号、无云端、无遥测，所有数据只保存在你自己的电脑上。

安装使用

  1. 点击上方「下载 Windows 版」，下载 MyToDo-v*-win64.zip。
  2. 解压到一个文件夹（建议不要放在 Program Files 等系统保护目录）。
  3. 双击 MyToDo.exe 即可运行，任务数据自动保存在同目录的 .sticky_tasks 文件夹。
  4. 想要桌面图标：右键 MyToDo.exe → 创建快捷方式，把快捷方式拖到桌面即可。

常见问题

第一次打开提示“Windows 已保护你的电脑”？
软件没有购买代码签名证书，点击「更多信息」→「仍要运行」即可；之后的启动不会再提示。
杀毒软件报警？
PyInstaller 打包的程序偶尔会被误报，源码全部公开在 GitHub 仓库，可自行审查或从源码运行。
数据存在哪里？怎么备份？
全部在软件目录下的 .sticky_tasks 文件夹（tasks.json 任务、settings.json 设置）。复制这个文件夹即完成备份。
支持 Mac / Linux 吗？
目前只提供 Windows 版。源码基于 Python + PySide6，理论上可自行在其他平台打包。
