安装使用

  1. 点击上方「下载 Windows 版」，下载 MyToDo-Setup-v*.exe 安装包。
  2. 双击安装包，按向导一步步安装（仅当前用户安装，不需要管理员权限）。因软件没有购买代码签名证书，首次运行若提示“Windows 已保护你的电脑”，可点击「更多信息」→「仍要运行」。源码全部公开在 GitHub 仓库，可自行审查或从源码运行。
  3. 安装完成后可从开始菜单或桌面快捷方式启动。
  4. 任务数据保存在 %APPDATA%\MyToDo，重装、更新都不会丢失。
  5. 软件内「设置 → 检查更新」可一键更新；卸载走「设置 → 应用」，卸载时可选是否删除数据。
  6. 旧版免安装 zip 用户：直接装新版即可；若把新版安装到旧的解压文件夹，原有任务数据会自动迁入。

功能亮点

🪟 半透明悬浮桌面无边框窗口透出壁纸，任务与桌面融为一体，透明度可自由调节。
📦 一键安装标准安装向导，无需 Python 环境；数据与程序分离，更新、重装不丢数据。
🎨 主题预设深空、暖夜、森林、海洋、薰衣草、素白六套预设，也可自定义颜色、字体与透明度。
🔒 锁定模式一键锁定窗口，防止误拖拽误编辑；Ctrl+L 快速切换。
🕘 历史任务完成与删除的任务进入历史记录，可随时恢复或彻底清除。
🌏 中英双语设置中一键切换中文 / English，重启即生效。
🔄 一键更新设置内检查新版本，发现新版自动下载安装，对接 GitHub Releases。
🛡️ 隐私优先无账号、无云端、无遥测，所有数据只保存在你自己的电脑上。
